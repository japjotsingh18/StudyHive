# Repository ownership

Ownership means stewardship, review, documentation, and recruiting additional reviewers. It does not restrict who may contribute.

| Path | Stewardship |
|---|---|
| `apps/web/`, `packages/ui/` | Frontend and accessibility maintainers |
| `apps/api/`, backend migrations | Backend and database maintainers |
| `packages/config/`, `scripts/`, `docker/`, workflows | Developer-experience and platform maintainers |
| `docs/`, root community files | Documentation and project maintainers |
| `plugins/` | Plugin and security maintainers after Phase 13 begins |
| `tests/` | Quality maintainers with affected domain owners |

The initial repository owner is the fallback reviewer until real teams exist. Security-sensitive paths require an experienced maintainer even when broad ownership applies.
